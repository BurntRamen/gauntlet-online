# Generated match-asset provenance

These assets were created for the Babylon production match renderer on
2026-08-03. They are original provisional assets and require project approval
before public cutover.

## Gameplay effects

The six source images were generated with the built-in OpenAI image-generation
tool, using one prompt per effect. Every prompt requested an isolated original
dark-fantasy digital-card-game effect on a flat green chroma background, the
Gauntlet graphite/navy/sapphire/bronze/pale-steel palette, no text or branding,
and no imitation of another game's visual identity.

- `attack-declare.webp`: diagonal sapphire and pale-steel strike with restrained
  bronze fragments.
- `block-raise.webp`: three-piece pale-steel defensive arc with sapphire rim.
- `payment-discard.webp`: three abstract parchment cards fragmenting into a
  bronze commitment seal; explicitly no coins or currency imagery.
- `damage-impact.webp`: restrained crimson/ember impact with graphite center.
- `priority-transfer.webp`: concentric sapphire priority rings and light nodes.
- `turn-transition.webp`: narrow bronze-white horizontal sweep with sapphire
  afterglow.

The generated PNG sources used a solid chroma background. The installed image
generation skill's `remove_chroma_key.py` helper produced the final alpha WebP
files with a soft matte and despill. Runtime files were then reduced to
512x512 WebP; all four corners are fully transparent and every file retains a
complete 0-255 alpha range. Generated-image originals remain in the
local Codex generated-image store; workspace intermediates are not runtime
dependencies.

## Gameplay icons

The 14 SVG icons are deterministic code-native assets generated by
`scripts/generate-match-icons.js`. They use a 24x24 viewBox, pale-steel primary
strokes, sapphire accent strokes, no embedded text, and no external artwork.
The set covers attack, block, payment, priority, placement, damage, pass,
inspect, confirm, cancel, draw, discard, connection, and sound.

## Match sound effects

The 15 sound effects are deterministic sample-free synthesis generated by
`scripts/generate-match-sfx.js`. No recordings, third-party samples, or cloned
sound designs are used. The generator combines sine partials, deterministic
noise, pitch sweeps, and short envelopes, then writes normalized 48kHz/24-bit
mono PCM WAV masters.

The set covers UI select/confirm/cancel, pass, payment, attack, block, damage,
priority, turn, place, draw, ability activation, victory, and defeat. The WAV
files are browser-compatible masters; an approved audio pipeline may later
transcode them to Ogg and create frequent-action variants.
